Load Habits

Habit Tracker Pro · source-derived sequence

  1. App delegate calls AppModel synchronously.
  2. AppModel calls HabitsFeature.startLoading() directly.
  3. The Feature starts and retains a reload task, then startup returns.
  4. The reload task queues the operation behind earlier habit work.
  5. The queued operation sets loading state and awaits the storage service.
  6. The Feature publishes saved habits or a load error on the Main Actor.
  7. The operation and reload tasks finish; their handles are cleared.

A later reload caller can await the same in-flight reload. The queue uses a separate task; actor calls do not create tasks by themselves.
