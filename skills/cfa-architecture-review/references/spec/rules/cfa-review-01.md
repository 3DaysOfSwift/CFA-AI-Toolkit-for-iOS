# CFA-SPEC-REVIEW-01: Apply the full conformance checklist

**Applies when:** Auditing a CFA implementation.

**Strength:** Required.

**Guidance:** Review the complete checklist against the actual app and report findings with evidence.

**Why:** A single passing rule cannot establish whole-app conformance.

**Example:** An audit checks ViewModel ownership, Feature state and task lifetimes.

**Verify:** Trace each applicable checklist item and distinguish unverified behaviour from passes.

**Full rule, context and examples:** [Review Checklist](../topics/29-review-checklist.md). This card is a reading aid; apply the complete canonical section.
