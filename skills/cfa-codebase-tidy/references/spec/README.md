# CFA specification reading map

The authoritative source is [cfa-specification.md](../cfa-specification.md). These generated topic files reproduce its sections, with relative links adjusted; the structured rule cards are summaries, not replacements for the full rules. Edit the source and catalogue together and run `node scripts/sync.mjs` to refresh them. Read the complete source for a whole-app audit; for a focused task, use the relevant topics below and check related boundaries. The [change gate](../cfa-change-gate.md), [Swift coding guide](../swift-coding-guide.md) and [decision rationale](../explanations/guide.md) provide additional guidance. Examples illustrate rules; only build optional capabilities when the app requires them.
