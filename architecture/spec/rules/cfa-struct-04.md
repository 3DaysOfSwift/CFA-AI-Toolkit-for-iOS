# CFA-SPEC-STRUCT-04: Do not create dumping-ground folders

**Applies when:** Organising files.

**Strength:** Required.

**Guidance:** Use folder names that describe the responsibility of their contents rather than vague catch-all folders.

**Why:** Related implementation remains easy to locate.

**Example:** A networking helper lives with the networking capability rather than a generic Helpers folder.

**Explanation:** [Why use an ownership-based project structure in our code?](https://www.3daysofswiftconcurrency.com/cfa/explanation/project-structure).

**Verify:** Inspect folder names and the actual responsibilities of their contents.
